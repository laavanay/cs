B) CSRF (Cross Site Request Forgery) – Procedure
1. Login to DVWA using admin credentials.
2. Set the DVWA security level to Low.
3. Open Burp Suite in Kali Linux.
4. In Burp Suite:
Go to Proxy → Options
Ensure the proxy listener is enabled on:
127.0.0.1 : 8080
5. Configure the Firefox browser proxy settings:
Open Firefox Settings
Search for “Proxy”
Select Manual Proxy Configuration
Set:
HTTP Proxy: 127.0.0.1
Port: 8080
6. Import the Burp Suite CA certificate into Firefox.
7. In DVWA, open the CSRF page.
8. Enter a new password and confirm it.
9. In Burp Suite, turn Intercept ON.
10. Click the Change button in DVWA.
11. Observe that Burp Suite captures the HTTP request.
12. Right-click the intercepted request and select:
Send to Repeater
13. Click Forward to continue the request to the server.
14. Open the Repeater tab in Burp Suite.
15. Modify the password parameter value in the request.
16. Click Send.
17. Observe the successful password change response in the response section.
18. Turn Intercept OFF.
19. Logout from DVWA.
20. Try logging in again using the old password.
21. Observe that login fails because the password was changed successfully.

Bash

Bash

5. Open the Snort configuration file:
Bash
sudo vi /etc/snort/snort.conf
6. Navigate to the rules directory:
Bash
cd /etc/snort/rules
7. Open the local rules file:
Bash
vi local.rules
8. Add the ICMP detection rule:
Bash
